Network options

Public STUN servers are run by third parties. Availability is not guaranteed, so check their terms before relying on one. Only your network address is shared with it, never your files.

Connection trouble?
  • Paste the full code with no extra spaces or line breaks.
  • Codes stop working when the tab closes. Create a new offer to retry.
  • Strict office networks and some VPNs block direct links. Try another network or a phone hotspot.
  • Devices on the same Wi-Fi connect fastest. Mobile carriers often block peer links.
  • Demo mode only works between tabs of this page in the same browser.
